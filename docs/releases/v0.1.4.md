LumaProfile 0.1.4 is a preview for Apple Silicon Macs on macOS 15 or newer. **If you have 0.1.2 or 0.1.3, update.**

**Fixed in 0.1.4**

- Adjust Live no longer changes a display's colour curve. In 0.1.2 and 0.1.3 it replaced the curve while the gauge was open and asked macOS to reload it on Done; on a two-display Mac that left both screens black until each display's colour profile was changed in System Settings → Displays. Adjust Live now only reads the meter.
- Because of that, the gauge reads through the active colour profile. With a calibrated profile active, the panel itself is slightly brighter than the gauge shows.

**Read first**

- The exact reason the reload produced black screens is not fully understood. This version removes the code that triggered it; it has not yet been re-run on the affected setup.
- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag. The packaged DMG has not been installed on real hardware.
- The floating "Waiting for you" prompt added in 0.1.3 has still not been confirmed on a real screen.
- The hardware checklist is incomplete: meter unplug mid-run, force-quit recovery, sleep handling, Restore Before after activation, and other displays or meters are unverified.
- Needs an X-Rite i1Display Pro or Plus colorimeter.

Generating a profile does not activate it; activation and verification are a separate, confirmed step. Measurements stay on your Mac. The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
