LumaProfile 0.1.6 is a preview for Apple Silicon Macs on macOS 15 or newer.

**New in 0.1.6: see what's happening during a run**

- While a calibration runs, the measuring window covers the screen, and on a Mac with one display LumaProfile itself is hidden. A status strip now sits at the bottom of the measured screen, above that window. It shows the current step in plain words, a progress count and bar, what (if anything) you need to do, and a Cancel button.
- When a run needs you, the strip becomes a "Waiting for you" prompt with **Continue**, so you never have to find the hidden app window.

**From 0.1.5**

- Fix for a screen going black on a Mac with two displays, plus automatic repair of a blacked-out screen while the app is open.
- A calibration runs to a finished profile without stopping to ask, Adjust Live closes by itself, and buttons use plain language.

**Read first**

- **The status strip has not been seen on a real screen yet.** On a small screen the measuring square may run behind it; this should not affect readings.
- **The two-display black-screen fix is not yet confirmed** by a full calibration on real hardware, and the automatic repair has never been triggered on real hardware.
- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag; the packaged DMG has not been installed on real hardware.
- Tested only with a Mac mini, a Dell S3221QS, an ASUS VP229, a MacBook Pro's built-in screen, and an X-Rite i1 Display Pro. Other displays and meters are unverified.

Generating a profile does not switch your screen to it; that is a separate step you choose. Measurements stay on your Mac. The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
