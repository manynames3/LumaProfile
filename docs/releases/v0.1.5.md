LumaProfile 0.1.5 is a preview for Apple Silicon Macs on macOS 15 or newer. **If you use two displays, update from any earlier version.**

**Fixed: a screen going black on a Mac with two displays**

- In 0.1.2 to 0.1.4, calibrating one display could turn the other one black partway through a run. The cause was reproduced on hardware: when the bundled ArgyllCMS 3.5.0 loads a calibration into the measured display, it zeroes the main display's colour curve instead.
- 0.1.5 no longer asks ArgyllCMS to load a calibration into any display. The second measuring stage applies the calibration to the test colours instead.
- While LumaProfile is open, it checks every display every two seconds. A display whose colour curve has gone black is reset to its default profile, and you get an alert.

**Easier to use**

- A calibration runs from start to finished profile without stopping to ask you anything, as long as the meter took a reading on that screen in the last ten minutes. It still stops for a real problem, such as the meter being in the wrong place.
- The progress card says which step is running (Tuning, Measuring, Building) and that no action is needed.
- Adjust Live closes by itself once brightness has stayed on target for five readings in a row.
- Plain-language buttons: **Use & Check New Profile**, **Use New Profile** (switch without the accuracy check), and **Go Back to Old Profile**, which now asks first and explains what it does.

**Read first**

- **Not yet confirmed on real hardware.** The black-screen fix was tested against the reproduced fault, but a complete two-display calibration on this build has not been run. The automatic repair has never yet been triggered on real hardware.
- The changed measuring method produced a working profile in one earlier run (average colour error 0.99), but it has not been compared against the old method on the same display.
- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag. The packaged DMG itself has not been installed on real hardware.
- Tested only on one Mac mini with a Dell S3221QS, an ASUS VP229 and an X-Rite i1 Display Pro. Other displays and meters are unverified.

Generating a profile does not switch your screen to it; that is a separate step you choose. Measurements stay on your Mac. The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
