LumaProfile 0.1.2 is a preview for Apple Silicon Macs on macOS 15 or newer.

**Read first**

- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag. The packaged DMG itself has not been installed on real hardware; the same source was run on one setup (Mac mini, Dell S3221QS, X-Rite i1 Display Pro).
- The hardware checklist is incomplete. Not yet verified: meter unplug mid-run, force-quit recovery, sleep handling, Restore Before after activation, and any other display or meter.
- Needs an X-Rite i1Display Pro or Plus colorimeter.

**What's new**

- New interface: four guided steps, dark design, clearer results.
- Adjust Live: a live brightness and white-point gauge, now the default on Prepare, reading about once a second.
- Before | After switch to compare the old and new profile by eye.
- Clearer Prepare checklist: a count, Tick All, and a note saying what Continue is waiting for.
- Profile names include the date.
- Fixes: cancel and Restore Before now reload calibration through ColorSync; an interrupted run no longer gets stuck when the display's profile was changed elsewhere; a crash when the meter tool exited early.

**How it works**

- Effort levels are 119 / 220 / 478 / 1,024 characterization patches. Calibration and verification add their own readings.
- Generating a profile does not activate it. Activation and verification are a separate, confirmed step.
- Measurements stay on your Mac. Export Report is privacy-reduced; still review it before sharing.

The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
