LumaProfile 0.1.8 is a preview for Apple Silicon Macs on macOS 15 or newer.

**New in 0.1.8: protects profiles made by earlier versions**

0.1.7 locks the profiles it installs so nothing else can rewrite them, but profiles made by earlier versions were left unlocked. 0.1.8 checks every profile LumaProfile has installed, each time it starts and at every login:

- **Healthy profiles are locked**, so ArgyllCMS can no longer swap them out.
- **Damaged profiles are moved out of the way**: a temporary copy ArgyllCMS left behind, or one whose calibration curve would show as a black screen. They go to `~/Library/Application Support/LumaProfile/Quarantined Profiles`, so macOS stops loading them, and LumaProfile tells you which ones. A screen that used one goes back to its standard profile; recalibrate it to make a new one.

**From 0.1.7**

- The cause of screens going black is blocked: no ArgyllCMS command that could write a screen's colour curve or profile is ever run.
- A background black-screen guard repairs a black screen within seconds, even when LumaProfile is closed and after the Mac wakes. It appears under Login Items as LumaProfile and can be turned off in Settings → Safety.

**Read first**

- Open LumaProfile once after installing, so the guard starts and earlier profiles are checked.
- The guard and the profile check have been tested on GitHub's cloud Mac, not yet on real hardware.
- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag; the packaged DMG has not been installed on real hardware.
- Tested only with a Mac mini, a Dell S3221QS, an ASUS VP229, a MacBook Pro's built-in screen and an X-Rite i1 Display Pro.

Measurements stay on your Mac. The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
