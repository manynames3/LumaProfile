LumaProfile 0.1.7 is a preview for Apple Silicon Macs on macOS 15 or newer. **Everyone on an earlier version should update.**

**Fixed: screens going black**

Earlier versions could leave a screen black during a calibration, or later when the Mac woke from sleep, even with LumaProfile closed. The cause is in how the bundled ArgyllCMS makes a calibration "stick" on macOS: it renames the screen's current colour profile, writes a temporary replacement in its place and renames the original back afterwards. If that is interrupted, the real profile stays replaced and the screen goes black every time macOS reloads it. Details: [Black-screen safety](https://github.com/manynames3/LumaProfile/blob/main/docs/guide.md#black-screen-safety).

0.1.7 closes this off in three layers:

- **The cause is blocked.** LumaProfile checks every ArgyllCMS command before running it and refuses any that could write a screen's colour curve or profile file.
- **Profiles are locked.** Profiles LumaProfile installs are marked Locked in macOS, so nothing else can rename or rewrite them.
- **A black-screen guard runs in the background,** even when LumaProfile is closed and after the Mac wakes. If a screen's colour curve goes black, it switches that screen to a safe profile within a few seconds and puts back any profile ArgyllCMS left swapped. It appears under Login Items as LumaProfile and can be turned off in Settings → Safety. It logs what it does to `~/Library/Logs/LumaProfile/display-guard.log`.

**Read first**

- **The guard has not yet been seen repairing a real black screen.** Its detection was proven on hardware; the full repair runs on the method that fixed the screens by hand.
- Open LumaProfile once after installing so the guard starts.
- This build is ad-hoc signed, **not notarized and not Gatekeeper-approved**. macOS will ask you to approve it once: right-click the app and choose **Open**, or allow it in System Settings → Privacy & Security.
- It was built and packaged by GitHub Actions from this tag; the packaged DMG has not been installed on real hardware.
- Tested only with a Mac mini, a Dell S3221QS, an ASUS VP229, a MacBook Pro's built-in screen and an X-Rite i1 Display Pro.

Also included from 0.1.5 and 0.1.6: hands-off calibration runs, the on-screen status strip, a self-closing Adjust Live, and plain-language buttons. Measurements stay on your Mac. The DMG includes the matching LumaProfile source, the ArgyllCMS 3.5.0 source, and licenses.
